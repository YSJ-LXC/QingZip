# 使用说明

## 解压

1. 打开 ZIP，或把 ZIP 拖入窗口。
2. 浏览目录。旧压缩包的中文文件名显示异常时，可以切换“中文旧格式”。
3. 点击“解压到文件夹”，选择存放位置。

程序会创建“压缩包名-解压”文件夹；同名时自动编号，不覆盖已有解压目录。操作完成后点击“打开结果”。

## 创建

1. 切换到“创建 ZIP”。
2. 添加文件、添加文件夹，或直接拖入。
3. 选择“标准压缩”或“仅打包，不压缩”。
4. 点击“创建 ZIP”，选择保存位置。

文件夹与空目录会保留。保存到已有 ZIP 时由保存对话框确认替换。点击“取消任务”或按 Esc 可取消压缩与解压，未完成的临时输出不会提交。

## 快捷键

| 按键 | 操作 |
| --- | --- |
| Ctrl + O | 打开 ZIP |
| Ctrl + N | 创建模式 |
| Ctrl + E | 解压当前 ZIP |
| Esc | 取消正在进行的压缩或解压 |

## 支持范围

未加密 ZIP、Stored / Deflate、ZIP64 目录字段、数据描述符、UTF-8 和旧 GBK/CP437 文件名，以及经过 CRC 验证的 Unicode Path 扩展。每次最多 4 GB 原始数据和 100,000 个条目。

不支持 RAR、7z、密码包、分卷、自解压 EXE、归档内编辑或单个条目预览。路径过深时请选择较短的解压位置。

解压会检查路径越界、大小写冲突、系统保留名称、符号链接及文件长度与 CRC32。程序不会自动运行解压出的文件。
